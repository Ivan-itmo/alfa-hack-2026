# BizCredit AI — Умный кредитный кабинет

AI-ассистент для банка Альфа-Банк. Помогает клиентам бизнеса понимать кредитные продукты и получать персональные финансовые советы.

## Запуск

### Требования
- Go 1.21+
- Доступ к AI API (http://10.154.0.1:8080/v1)

### Установка зависимостей
```bash
go mod tidy
```

### Запуск сервера
```bash
go run ./cmd/server/
```

Сервер запустится на `http://localhost:8081`

### Переменные окружения
```bash
SERVER_ADDR=0.0.0.0      # Адрес сервера
SERVER_PORT=8081          # Порт сервера
AI_BASE_URL=http://10.154.0.1:8080/v1  # URL AI API
AI_MODEL=gemma4:12b       # Модель нейронки
AI_API_KEY=               # API ключ (если нужен)
AI_TIMEOUT=30             # Таймаут в секундах
```

## API Endpoints

### 1. Сравнение кредитных продуктов
**POST** `/api/v1/advice/compare`

Объясняет различия между кредитными продуктами простыми словами.

```json
{
  "product_a": "overdraft",
  "product_b": "revolving_credit"
}
```

**Response:**
```json
{
  "type": "comparison",
  "product_a": "overdraft",
  "product_b": "revolving_credit",
  "advice": "Овердрафт — это как страховка на вашем счете..."
}
```

### 2. Контекстная подсказка
**POST** `/api/v1/advice/contextual`

Анализ параметров клиента и выдача совета по кредиту.

```json
{
  "client_id": "client_123",
  "revenue": 5000000,
  "net_profit": 800000,
  "requested_amount": 3000000,
  "requested_term": 6,
  "payment_type": "monthly",
  "credit_product": "term_loan",
  "context": "Нужно资金 на закупку товара"
}
```

**Response:**
```json
{
  "type": "contextual_advice",
  "client": "client_123",
  "advice": "Ежемесячный платёж составляет 40% вашей чистой прибыли..."
}
```

### 3. Объяснение банковского решения
**POST** `/api/v1/advice/explain-decision`

Объясняет причины отказа или встречного предложения понятным языком.

```json
{
  "decision_type": "counter_offer",
  "original_amount": 5000000,
  "original_term": 6,
  "counter_amount": 3000000,
  "counter_term": 12,
  "reasons": [
    "Высокая нагрузка на денежный поток",
    "Краткосрочный период repayment"
  ]
}
```

**Response:**
```json
{
  "type": "decision_explanation",
  "decision": "counter_offer",
  "explanation": "Банк предлагает снизить сумму кредита..."
}
```

### 4. Health Check
**GET** `/health`

```json
{
  "status": "ok"
}
```

## Сценарии использования

### Сценарий 1: Объяснение различий между кредитными продуктами
Клиент не понимает, чем овердрафт отличается от оборотного кредита. Система объясняет простыми словами с аналогиями.

### Сценарий 2: Контекстная подсказка при заполнении
При вводе параметров кредита система анализирует данные и даёт совет:
- «Ежемесячный платёж превышает 40% вашей чистой прибыли»
- «Рекомендуем увеличить срок кредита с 6 до 12 месяцев»

### Сценарий 3: Расшифровка банковского решения
Когда банк отказывает или предлагает встречное предложение, система объясняет:
- Почему банк так решил
- Что это значит для клиента
- Какие есть варианты
